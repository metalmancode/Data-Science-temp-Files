# Data Science Tools and Ecosystem

This repository contains a Jupyter Notebook created as an exercise for a data science course. The notebook summarizes the various tools, languages, and libraries that form the ecosystem of data science.

## 📓 Notebook Summary

The file `DataScienceEcosystem.ipynb` demonstrates a basic understanding of the data science landscape.

### Objectives Covered:

* List popular programming languages used in Data Science.
* Explore common libraries and tools for Data Science tasks.
* Demonstrate basic arithmetic operations in Python.
* Understand the basics of data manipulation and analysis.
* Recognize key steps in the data science workflow.
